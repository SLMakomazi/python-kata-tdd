# Python Katas — Test-Driven Development (TDD)

This repository contains my Python coding katas, practised using **Test-Driven Development (TDD)**.

Each kata lives on its own Git branch to keep implementations, tests, and learning notes separate.

## Kata branches

- [`string-calc`](../../tree/string-calc) — String Calculator Kata, including Python implementation and pytest tests.
- [`rock-paper`](../../tree/rock-paper) — Rock Paper Scissors Kata, starting from a clean branch.

## My TDD workflow

1. **RED** — Write a failing test for one requirement.
2. **GREEN** — Write the smallest amount of code to pass the test.
3. **REFACTOR** — Improve the code while keeping all tests passing.

Switch to a kata branch to explore the code or run its tests. The `main` branch intentionally contains only this README.
